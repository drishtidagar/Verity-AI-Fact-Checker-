# 30-second demo
0–4s: Open Overview. “Verity is an evidence-first fact-checking workspace for PDFs.”
4–8s: Open New Audit and upload a sample PDF.
8–15s: Run the review; show progress and claim extraction.
15–23s: Expand one finding; show verdict, explanation, source category and URL.
23–27s: Show Audit History / Analytics.
27–30s: Download the JSON report.
